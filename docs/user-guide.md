# Summon 使用指南

## 轮盘菜单

默认快捷键是 **Ctrl + Space**。轮盘在鼠标所在显示器呼出，靠近屏幕边缘时会向内适配。移动鼠标按方向选中菜单项，中心名称随候选变化；鼠标不必停在图标圆内。

左键确认叶子项或进入子菜单。子菜单中的中心和父菜单返回节点用于返回上一层；根菜单点击中心关闭轮盘。鼠标后退侧键用于返回，前进侧键用于进入当前高亮的子菜单。按 Esc 取消，窗口失焦也会关闭轮盘。

从外围节点按住左键可拖动选择；达到起拖条件后，候选节点与连线随指针移动。足够移动后停顿或明显转向可进入子菜单；叶子动作在松手确认时执行。拖动回中心并松手取消选择，保留当前层。

设置的“轮盘 → 菜单”提供名称、图标、动作参数与启用状态编辑。单击菜单项选中，双击子菜单进入编辑层级；可拖动整理顺序与层级。有效修改自动保存，未完成的菜单项草稿需要继续编辑或丢弃。

“界面”中的轮盘动效开关控制展开、层级过渡、局部光斑、图标微磁吸和按压装饰。关闭动效或系统要求减少动态效果时，保留选中提示、返回路径和真实拖动位置。

## 剪贴板历史

开启采集后，Summon 在后台保存复制的文本、图片和文件。轮盘的剪贴板入口打开记录面板，支持搜索、类型筛选、收藏、置顶和删除。

选择记录会把内容恢复到系统剪贴板，再由你在目标应用中粘贴；不会自动向其他应用发送粘贴。默认复制成功后关闭面板，固定窗口时保持显示。右键“查看详情”可查看完整文本、图片或文件信息，查看本身不恢复剪贴板。

默认单次内容上限为 50 MiB，普通历史上限为 500 条，历史资产容量目标为 2 GiB。收藏不参加普通历史的自动清理。文件可保存副本；超限或读取失败的内容可能只保留元数据。文件夹不会递归采集，特殊应用的私有剪贴板格式也不保证全部支持。

在设置的剪贴板栏目调整采集类型、历史限制、操作和数据位置。当前没有图片文字识别或文件内容搜索。

## 文字备忘录

备忘录管理窗口用于新建和编辑记录。记录可包含标题、正文、备注、颜色以及多个标签；同一记录在不同标签下共享内容。隐藏记录仍显示标题，正文和备注以占位符遮挡；你可主动显示、复制或插入。

要调用常用文字：

1. 创建标签并设置唯一缩写，例如 `addr`。
2. 将需要调用的记录关联到该标签。
3. 在目标应用输入框中输入缩写；使用拼音输入法时先确认上屏。
4. 按默认 **Ctrl + Win**，在候选面板中选择记录。

无法可靠读取缩写、没有匹配记录或不支持插入时，会保留原输入并打开管理窗口。按 Esc 或取消候选不会执行插入。支持程度取决于目标应用、控件和输入法，不保证所有网页与桌面输入框都能直接插入。

编辑后明确保存才更新记录。离开未保存编辑时遵循窗口的草稿确认；隐藏记录失焦后恢复遮挡。删除标签会连同该标签的关联记录删除，即使记录也属于其他标签；操作前会显示影响范围。

## 快捷键与常驻

轮盘快捷键与备忘录调用快捷键可在设置中录制。只有系统注册与配置保存成功，新组合才生效；冲突或保存失败时保留原组合。某些系统保留组合不可用。

关闭轮盘或工具窗口不代表退出后台应用。完整退出使用托盘右键菜单的“退出”。开机启动等选项位于通用设置。

## 数据与升级

| 默认位置 | 保存内容 |
| --- | --- |
| `%APPDATA%\Summon\menu.json` | 菜单定义。 |
| `%APPDATA%\Summon\config.json` | 应用设置与轮盘快捷键。 |
| `%APPDATA%\Summon\clipboard` | 剪贴板数据库和资产，实际位置可在设置中修改。 |
| `%APPDATA%\Summon\text-memo` | 备忘录数据与调用快捷键。 |
| `%APPDATA%\Summon\menu-assets` | 菜单图标缓存与资源。 |
| `%APPDATA%\Windows Pie Menu` | Electron 缓存和运行配置。 |

安装包不携带个人数据，但启动后会读取上述目录中的已有内容。升级前如需备份，请先退出应用，再复制数据目录；不要在数据库仍运行时直接复制。

备忘录持久数据使用 Windows 当前用户保护，不应将加密文件直接作为跨账号迁移方法。内容隐藏只是界面表现，使用电脑的人仍可能通过应用的主动显示或复制功能读取记录。
